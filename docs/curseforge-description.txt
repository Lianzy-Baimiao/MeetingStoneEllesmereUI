MeetingStoneEllesmereUI

Only for MeetingStone_Happy, new UI and classic UI editions, running under EllesmereUI.

New UI download: https://www.curseforge.com/wow/addons/meetingstone-happy

Features
- A clean, dark, flat skin across activity browsing, group management, recent players, settings and the block list.
- In-game appearance settings for fonts, window/tab colours, transparency, list stripes and hover/selection highlights. Most changes apply instantly.
- One scrollable filter window with expandable advanced conditions and apply/refresh actions.
- Edition-aware filtering: seasonal dungeon selection and role shortcuts for new UI; original dungeon, class, need/avoid and reset controls for classic UI. Each edition keeps its own filtering logic.

Requires EllesmereUI and EllesmereUIBlizzardSkin / Blizz UI Enhanced with third-party skinning enabled. Enhanced filters require the matching MeetingStoneEX.

Version 1.4.19 adds the Retail 12.1.5 Interface tag (120105), with no skin behavior or settings changes. The release archive now includes the existing MIT license. Fully exit and restart the game after installation, and keep SavedVariables. Live client behavior still requires in-game verification.

中文

仅适用于 EllesmereUI 环境下的 MeetingStone_Happy 集合石开心快乐新UI版、经典UI版。

新UI版下载：https://www.curseforge.com/wow/addons/meetingstone-happy

主要功能
- 统一界面风格：深色扁平面板与按钮，覆盖活动查找、队伍管理、最近玩友、设置及屏蔽列表。
- 游戏内调整外观：字体大小、窗口与标签页颜色/透明度、列表斑马纹、悬停及选中效果，多数设置即时生效。
- 合并筛选入口：在同一窗口滚动查看条件、展开高级筛选、应用并刷新，不必来回切换面板。
- 按版本适配筛选：新UI版提供赛季副本选择和职责快捷项；经典UI版保留副本、职业、需要/避开及重置控件，沿用各自的筛选逻辑。

需要 EllesmereUI 及 EllesmereUIBlizzardSkin / Blizz UI Enhanced 组件，并开启第三方插件美化。增强筛选需要对应版本的 MeetingStoneEX。

1.4.19 增加正式服 12.1.5 的 Interface 标记（120105），不改动皮肤行为或配置；发布包补充附带现有 MIT 许可证。安装后请完全退出并重启游戏，保留 SavedVariables；实机行为仍需游戏内验证。
